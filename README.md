# Indian Vastra Elegance

A custom e-commerce website for selling Indian traditional clothes for man and women. The name of the business would be Indian Vastra and it's operative in India, USA, Canada and Australia. Add translation plugin for Tamil language and also currency convertor for the region the business is operated. The theme of the website should be premium, elegant and simple using light colors like white on gold and black. Add the shipping calculator, add to cart and check out method. Relly clean interface and easy to navigate. Add motion graphics on scroll feature.
